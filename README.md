# BDOH

Base de Données des Observatoires Hydrologiques, réécrite pour Symfony 7.4 et PHP 8.4.

Ce dépôt porte l'application en service, écrite pour Symfony 2.8 et PHP 7.1, vers des versions maintenues, en gardant son comportement, ses adresses et ses données. Rien n'y tourne encore : l'application en service reste celle du dépôt d'origine jusqu'à la bascule. L'avancée est dans [ROADMAP.md](ROADMAP.md).
